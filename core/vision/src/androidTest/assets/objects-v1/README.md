# objects-v1

Original synthetic rectified screenshots generated by `../../fixtures/generate_objects.py`
using Python stdlib, seed 22. No game screenshots or personal pixels. `annotations.json`
uses board-relative x/y/radius on a 400 by 400 surface, origin (0,0).
The tests deliberately use physical bounds (10,20)..(410,420) mm to check translation.

- complete/scaled/noisy: nine objects each (four pockets, three disc classes, striker,
  rectangular obstacle); scaled is 601 px, others 401 px. Noise is independent RGB +/-7.
- occluded: two merged red circles, a half white circle and a clipped red circle.
  Expected recognitions are empty: these shapes are deliberately unclassifiable under
  the complete-circle contract. These four source circles are **not** recall positives.
- false-positives: red ring, tiny red circle, white line and pocket-colored interior circle.
- empty: background only.

Precision/recall covers only the 27 complete labeled objects, with one-to-one class,
center (<2 mm) and radius (<2 mm) matching. Rectangle radius means enclosing bound.
Rejection fixtures separately assert zero detections. This small calibration-aligned
suite verifies mechanics and conservative rejection, not real-game accuracy or broad
robustness to skins, lighting, texture, shadows, patterned discs or mild occlusion.
