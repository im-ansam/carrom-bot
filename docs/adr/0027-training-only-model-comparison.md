# ADR 0027: Offline model comparison with sealed future evidence

Accepted for CB-38, 2026-11-17. Extends ADR 0026 without changing production code,
mm-labelled contracts, Android dependencies or synthetic demo configuration.

CB-37's three historical holdouts were already viewed. They remain immutable
historical evidence and do not enter CB-38 model selection or get rescored. The
six development wall shots support six leave-one-shot-out internal folds, not
fresh validation. A committed plan precedes new fitting, fixes compact candidates,
bounds, optimizer work, equal-shot objective, sensitivity and simplicity policy.

Compare constant drag/linear proxy with one extra parameter at a time: nonnegative
speed drag or a bounded monotone arrow exponent. Implement these only in Python
offline tooling. Analytic between-contact motion and swept rectangular walls use
actual observation times; display holds/gaps are retained. Release uncertainty is
a coherent sensitivity refit, never a freely fitted clock per shot. Direction
remains an observed conditional initial state, not a blind UI prediction.

Retain explicit failed targets, local optimizer limitations, bound solutions and
identifiability diagnostics rather than promoting the least-bad hypothesis to a
profile. Record exact numeric input hashes and retain all v1 measurements/results.
All original media remains external/read-only. Public-source prior art is assessed
for evidence, license and applicability; no external code/assets/constants adopted.

The next acquisition separates development and sealed validation by preassigned
attempt, holds game/build/equipment/display fixed, measures a full-range visible
input proxy, and stages long isolated striker, single-target and pocket experiments.
Freshness is lost if validation trajectories are inspected for model/annotation
repair. A new sealed batch is then necessary. Physics acceptance, real-game vision
and device alignment remain separate gates before scoped live advisory integration.
